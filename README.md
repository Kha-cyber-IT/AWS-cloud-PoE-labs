# ☁️ 100 Days of AWS | Portfolio of Evidence (PoE)

- **Status:** Day 50/100
- **Curriculum:** KodeKloud
- **Primary Focus:** Cloud Administration & Infrastructure

This repository serves as a technical Portfolio of Evidence documenting my journey to master **Amazon Web Services (AWS)**. It contains lab reports, architectural notes, and hands-on infrastructure deployments.

## 📊 Competency Breakdown (First 50 Days)
I have structured my learning to align with real-world roles, focusing heavily on **SysOps Administration** to build a solid infrastructure foundation.

| Role Focus | % of Labs | Key Skills Practiced |
| :--- | :--- | :--- |
| 🟧 **SysOps Administrator** | 64% | EC2 Management, VPC Peering, ELB (Load Balancers), S3 Lifecycle |
| 🟦 **DevOps Engineer** | 16% | CloudFormation, AWS CLI, Docker/ECR, ECS/EKS |
| 🟥 **Security Engineer** | 10% | IAM Policies, KMS, Security Groups, NACLs |
| 🟨 **Data Engineer** | 10% | RDS, DynamoDB, Kinesis, Database Migration (DMS) |

- **Day 01-15:** AWS Basics (EC2, IAM, VPC Basics)
- **Day 16-20:** Storage (S3, EBS, EFS) & CloudFormation
- **Day 21-30:** Advanced Networking (Route53) & Databases (RDS)

- **Day 41-50:** Monitoring (CloudWatch), EKS & Security
